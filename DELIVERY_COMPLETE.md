## 🚀 How to Use (3 Simple Ways)

### Option 1: JSON Only (1 line)
```dart
await ExportIntegrationHelper.quickExportJson(context, employees, weekDates);
```

### Option 2: JSON + PDF (1 line)
```dart
await ExportIntegrationHelper.exportWithPdfWorkflow(context, employees, weekDates);
```

### Option 3: Send to Server (5 lines)
```dart
await ExportIntegrationHelper.exportToHttpsEndpoint(
  context, employees, weekDates,
  endpointUrl: 'https://api.yourserver.com/export',
  apiKey: 'your-api-key',
);
```
